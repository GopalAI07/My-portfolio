# Gopal Chauhan — 3D IT Professional Portfolio

A modern, high-performance, interactive **3D Portfolio** built for **Gopal Chauhan** (Artificial Intelligence & Data Science Engineer) using **Vite, React 18, Three.js (@react-three/fiber & @react-three/drei), Tailwind CSS, and Framer Motion**.

---

## 🚀 Quick Setup & Run

### 1. Install Dependencies
Run the following command in the project directory to install all packages listed in [package.json](package.json):

```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000` or the port shown in your terminal.

### 3. Build for Production
```bash
npm run build
```

## 🌟 Key Features

1. **Interactive 3D Hero Scene**:
   - Built with Three.js and `@react-three/fiber`
   - Floating morphing AI core with `MeshDistortMaterial`
   - Orbiting quantum rings and satellite 3D tech nodes (`Python AI`, `FastAPI`, `React 18`, `Gemini AI`, `Django`, `WebRTC`)
   - Interactive particle nebula constellation.

2. **Ambient Particle Mesh Canvas**:
   - Custom dynamic 2D/3D interconnected particle field that gently reacts to mouse movements across all sections.

3. **Curated Sections Based on Resume**:
   - **Executive Summary & Profile**: Bio, core competencies, multilingual badges, and hobbies.
   - **Skills & Tech Matrix**: Categorized into *AI/Data Science*, *Backend & Systems*, *Frontend*, and *Databases/Cloud* with animated proficiency progress bars.
   - **Featured Projects**:
     - *AI Meeting Hub* (FastAPI, React 18, WebSockets, WebRTC, Gemini AI, PostgreSQL, Vercel & Render)
     - *Election Analysis* (Streamlit, Plotly, Wordcloud, NumPy, Pandas)
     - *Library Management System* (Django MVT, MySQL, Bootstrap)
   - **Education & Credentials**:
     - B.E. in Artificial Intelligence & Data Science from *Rizvi College of Engineering* (CGPI: 7.83)
     - Higher Secondary (H.S.C.) in Science from *Shri T.P. Bhatia College of Science*
     - Verified certifications in JavaScript & Python.
   - **Interactive Developer CLI Terminal**:
     - Interactive terminal where recruiters can type commands (`skills`, `projects`, `education`, `contact`, `hire`, `about`, `clear`) or click one-tap command chips.
   - **Communication Portal**:
     - Instant copy buttons with feedback for Email and Phone, pre-filled contact form, and celebratory confetti burst.
   - **Interactive ATS Resume Modal**:
     - Built-in preview modal with clean print layout (`window.print()`) for direct PDF export.
   - **Synthesized Web Audio Cyber Soundscapes**:
     - Subtle interactive clicks and chimes synthesized natively via the Web Audio API with an on/off toggle.
